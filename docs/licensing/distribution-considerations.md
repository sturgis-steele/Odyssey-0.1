# Distribution review

The shipment unit includes more than the Rust binary. Record the exact executable, assets, operating-system image, model, tokenizer/template, licenses and checksums for each hardware release. Odyssey's own product license remains an owner decision.

| Component | Findings and release work |
| --- | --- |
| Rust crates | The [locked inventory](rust-dependencies.md) lists direct, development, transitive and target-only crates. Retain copyright and license text. For dual MIT/Apache crates select a permitted option consistently. matchit requires both MIT and BSD-3-Clause. unicode-ident adds Unicode-3.0 to its alternative software licenses, and ICU crates/data carry Unicode-3.0. foldhash uses Zlib. Preserve individual notices and required attribution. |
| Conditional alternatives | r-efi offers MIT, Apache-2.0 or LGPL-2.1-or-later. The target builds omit it. The scan also flags valuable and rsqlite-vfs as outside the two runtime/build graphs with no standalone top-level license text. Inspect source notices if target/features change. |
| Native code | rusqlite and libsqlite3-sys use MIT. The bundled SQLite amalgamation carries a public-domain dedication. Account separately for Rust std, LLVM/GCC runtime components, MinGW-w64 and glibc as appropriate to the binary or OS image shipped. Review the GCC runtime exception for eligible compiled output and LGPL distribution/source obligations for any shipped runtime libraries or modified OS image. |
| llama.cpp | The upstream project uses MIT. Archive its exact license and notices from included third-party libraries and native backends. The installed Ollama-packaged server and an upstream CPU package are development fixtures. Review the specific binary bundle chosen for distribution. |
| LFM3 model | The local LFM3 1.7B Q4_K_M manifest identifies model SHA-256 3793e1e6e2266919d6e015287221b41100175a98eddaba92e111aed3b05c93c4 and license blob 4d28ca14dedc0b3d0fcc2b3339f0e79931faa33874f3d24f522183a8fc70068c. LFM Open License v1.0 contains a commercial-use condition using a US$10 million annual-revenue threshold. Section 4 covers license delivery, change notices and preservation of attributions. Confirm eligibility, the threshold's application to the selling entity and any separate license with Liquid before shipping. |
| Other weights | Qwen's publisher labels its Qwen3 1.7B GGUF Apache-2.0. Check each exact quantization, upstream revision, template and conversion or adapter license separately. No weights are tracked in this branch. |
| Frontend | Ship Vite's generated THIRD-PARTY-NOTICES.md with dist. Barlow and IBM Plex Mono use OFL 1.1. Retain font notices and respect reserved names on modified fonts. Lucide includes ISC and inherited Feather MIT notices. Record the source of the bundled terrain illustration and Odyssey artwork. |
| Future Kiwix and content | No runtime integration or archives are present. Kiwix tools use GPLv3 terms. Distributing a separate executable still requires meeting its redistribution obligations. Review any future direct linking separately. Each ZIM or dataset needs its own attribution, copyright, commercial-use and share-alike review. |

Regenerate the crate inventory from Cargo.lock for both targets. The audit script can collect candidate notice text from the resolved packages. Inspect nested vendor files and data licenses manually. cargo-deny can enforce an SPDX policy and report newly introduced license choices in CI. cargo-about can generate presentation-ready attribution. Neither tool can decide model eligibility, OS-image obligations, modified artwork rights or the actual contents of a shipping image.

Primary references are the [SQLite dedication](https://www.sqlite.org/copyright.html), [llama.cpp license](https://github.com/ggml-org/llama.cpp/blob/master/LICENSE), [Liquid model license](https://huggingface.co/LiquidAI/LFM3-1.7B-GGUF/blob/main/LICENSE), [Qwen publisher](https://huggingface.co/Qwen/Qwen3-1.7B-GGUF), [Kiwix tools](https://github.com/kiwix/kiwix-tools), [Open Font License](https://openfontlicense.org/open-font-license-official-text/), [Unicode license](https://www.unicode.org/license.txt) and [GCC runtime exception](https://www.gnu.org/licenses/gcc-exception-3.1.html). Review the actual notices in the release staging directory alongside these sources.

## Dependency maintenance and timezone data

The final direct crate repositories were checked against their upstream archive status and recent release or repository activity. The preliminary chrono-tz choice was archived in November 2026. The release uses Jiff 1.0.3 under its MIT or Unlicense terms. Windows includes jiff-tzdb through jiff-tzdb-platform, while Linux reads the local zoneinfo database. Preserve the packaged licenses and COPYING file and track timezone database updates with the OS image or Cargo.lock. dotenvy and num-traits have comparatively old stable releases and active upstream repositories.
